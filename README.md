# INDIA — 5 JOURNEYS（大学生のためのインド、5つの旅。）

日本の大学生向けに、インド国内の旅行先5地域（デリー＆アーグラ／ジャイプル／バラナシ／ケーララ／ラダック）を
**8つの評価軸 × 7タイプの旅人**で多角的に評価・紹介するサイトです。
**対象はハイエンドAndroidスマホの横画面・全画面表示のみ**で、WebGLによる3D表現を妥協せずに使っています。

## 3Dグラフィック（three.js r169 / WebGL2）
| シーン | 内容 |
|---|---|
| **深度3Dヒーロー** | 実写真を、ニューラル深度推定（Depth Anything V2）で作った深度マップで約10万頂点のメッシュに押し出して立体化。ジャイロとタッチで視差が動く。地域の切り替えは奥から手前へ深度順に溶けていく。光る境目、空気遠近、塵やボケのパーティクル付き |
| **3D地形マップ** | 実際の標高データ（SRTM/GMTED、AWS Terrain Tiles）からインド亜大陸を約31万頂点で立体化。陰影を焼き込み、太陽光・海面の反射・ヒマラヤの雪のきらめき・等高線・光る国境線を描画。デリーを中心に地図が広がり、光の柱のピン、航路アーク（東京→デリー含む）、タップでカメラが飛ぶ演出、ドラッグで回転 |
| **アンビエント背景** | ページ全体に星雲とパララックスの星空。今見ているセクションの地域色に合わせて色が変わる |
| **ポストエフェクト** | HDR（HalfFloat）、MSAA 4x、Unreal Bloom、色収差、ビネット、フィルムグレイン、ニュートラル・トーンマップ |
| **DOMの3D** | 地域カードや見どころを3Dカバーフローで表示。カードの光沢と見出しの影がジャイロに合わせて動く |

WebGL2が使えない環境では、これまでの静的な写真とSVG地図を表示します。

## 横画面・全画面のUI
- 左端のサイドレールでナビゲーション（ノッチなどのセーフエリアに対応）。2カラム構成で、左の見出しはスクロールしても固定
- 詳細は右から出るドロワーで表示。最初のタップで全画面表示と横向き固定（Fullscreen API ＋ `screen.orientation.lock`）
- `manifest.webmanifest` は `display: fullscreen` と `orientation: landscape`。縦向きにすると「横向きにしてください」という案内を表示

## 高解像度と画質
- **写真**：`pipeline/tools/photo_sources.py` が Flickr（oEmbed＋最大サイズ）と Wikimedia Commons API から、各写真の**最大解像度の原本・撮影者・ライセンス**を取得して `data/photos.json` に記録します。解像度が低かった9枚は Commons の高解像度原本に差し替えました。
- **a1**：原本（最大3840px）から 640 / 960 / 1280 / 1920 / 2560 px（ヒーローとギャラリー先頭の写真は3200 pxも）を AVIF＋WebP で書き出します。JPEG は1920 pxまでの互換用です。写真ごとの `meta.json` に署名を残し、変更のない写真は再処理しません。Wikimedia のレート制限には指数バックオフで対応します。
- **WebGL**：端末の本来の解像度（最大3倍のDPR）で描画します。フレーム時間を見て DPR を 3 → 2.5 → 2 → 1.6 と自動で下げるガバナー付き。GPUのコンテキストが失われた場合は、静的な写真とSVGに切り替えます。
- **配色**：ヒートマップの配色を OKLab で補間し、明るさが均等に上がるようにしました。文字色はセルごとに WCAG の相対輝度から決めています。

## 品質監査で直した主なバグ（L2ラウンド）
- オーバーレイ（メニュー・ドロワー・ライトボックス）のスクロールロックが重なると解除されない／フォーカスが外に逃げる → ロック管理を1か所にまとめ、フォーカストラップを追加
- ドロワーを素早く開き直すと閉じるアニメが新しい内容を消す・横画面のスワイプ方向が逆 → タイマー競合を解消し、右スワイプで閉じるように
- 地域ページの季節グラフで長期休みのハイライトが別の月に付く（Jinjaの `loop` 変数の取り違え）
- ランキングの同点が不安定に並び替わる／重みをすべて0にすると NaN → 同点は同順位にして「同点」バッジを表示、全0のときは警告と「均等に戻す」ボタン
- VS 比較で同じ地域を左右両方に選べる → 反対側で選ばれている地域は選べないようにし、左右入れ替えボタンを追加
- レーダーで全系列を外すと空の図になる → 最低1つは残す
- 休みタブのラベル判定が `<small>` を含むと失敗する
- ライトボックス：前後ボタン・スワイプ・前後の写真の先読み・撮影者とライセンスの表示を追加
- 最初のタップで全画面にする処理が、ボタンの操作を横取りする
- 横画面のレールでタブがメニューや全画面ボタンと重なる／英字の見出しが単語の途中で折り返す／クレジットがはみ出す／カードのCTAの位置がずれる／ギャラリーの画像が拡大されてぼやける　ほか多数
- 3D地図：ラベル同士が重なる → 衝突を避けて引き出し線を付ける。ピンのタップ判定を追加し、全体表示では全ピンが入るように自動でフレーミング。縦スクロールを邪魔しないドラッグ（`touch-action: pan-y`）
- PWA：アイコンが404だった（touch-icon が生成されていなかった）→ マンダラアイコンを 180 / 192 / 512 px とマスカブル版で生成。manifest に id と scope を追加
- JSON データ内の `</script>` をエスケープ、ボタンに `type`、タブやトグルに ARIA 属性（`aria-selected` / `aria-pressed`）を設定

## 6エージェントのビルドクルー（依存関係のDAGを並列実行）
| エージェント | 担当タスク |
|---|---|
| ① ASSET & DEPTH | a1 写真50枚の取得と最適化 → a1b 深度推定（ONNX int8） |
| ② WORLD BUILDER | a4 SVG地図 → a4b 3D地形（高さ・陰影・マスク） |
| ③ DATA SCIENTIST | a2 コンテンツ検証 → a3 ペルソナ集計・モンテカルロ検証 |
| ④ VISUAL DESIGN | a5 チャート ∥ a7 OGP画像 |
| ⑤ EDITORIAL & SITE | c5 原稿レビュー（LLM＋ルール）→ a6 サイト生成 |
| ⑥ QA LEAD | a8 静的監査 ∥ a9 横画面Android（915×412・WebGL2）の実機相当QA → c6 デザイン講評（LLM＋画像計測） |

- 6エージェントは同時に動き、各タスクは依存するタスクが終わった時点で始まります。
- メモリを多く使うタスク（深度推定・地形・ブラウザ）は、RAMが少ない環境では別プロセスで1つずつ実行します。
- **LLM**：ビルド開始時に、OpenAI互換プロキシへ6エージェント分のリクエストを並列に送って疎通を確認します（`pipeline/llm.py`）。
  使えない場合（クレジット不足など）は、各エージェントがルールベースで処理を続けます。結果は `reports/llm_status.json` に記録します。

```bash
pip install jinja2 pillow pillow-heif requests beautifulsoup4 onnxruntime numpy openai pyyaml playwright
python -m playwright install --with-deps chromium
python3 -m pipeline.tools.photo_sources  # 写真の原本URL・撮影者・ライセンスを更新
python3 -m pipeline.run               # フルビルド（6エージェント）
python3 -m pipeline.run --skip-assets # 写真処理をスキップ
python3 -m pipeline.quick_shot index.html top,map   # 1ページだけ横画面WebGLのスクリーンショットで確認
pipeline/deploy_pages.sh              # dist/ を gh-pages ブランチへ公開
pipeline/autosave.sh 120              # 作業中の自動コミット＋push
```
